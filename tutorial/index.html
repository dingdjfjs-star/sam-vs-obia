1 · 这个项目是什么

把 Meta SAM2（零样本，只看真彩色 RGB） 和 手写 OBIA（Baatz & Schäpe 多尺度区域生长，4 波段 + 19 维特征） 放进同一幅 512²×4 波段合成场景（seed=20260829，自带像素级真值 + 图斑真值），用同一套下游分类器与指标代码正面对比。一句话结论：

SAM 赢边界（边界 F 最高 0.95 vs OBIA 0.48）和速度（GPU 3.2s vs CPU 78s，24×）；输开箱 OA（0.924 vs 0.959）、尺度可控性与默认覆盖率（默认阈值漏掉 23.2% 场景）。提示把同一图斑的 IoU 从自动模式 0.376 → 点 0.602 → 框 0.870。

左图是 SAM 真正看到的输入（64² 缩略，原图 512²）。注意它没有 NIR——零样本的真实约束。

2 · 对比怎么做到公平

三个产物形态完全不同的方法（手写 MRS label 图 / SLIC 超像素 / SAM 重叠 mask 集）要同台，只有一条路：全部变成"非重叠 label 图"，过同一道协议门——

label 图 → 19 维图斑特征 → 同种子 RandomForest → 回填分类图 → 三指标
                                                    ├─ 全图 OA
                                                    ├─ 椒盐率（3×3 多数类不一致像素占比）
                                                    └─ 边界贴合 F1（tol=2px 双向匹配）
                                                         ├─ cls_bF1：分类图边界 vs 地类真值
                                                         └─ seg_bF1：分割 label 图边界 vs 图斑真值

指标/特征/分类代码全部 sys.path 桥接自姊妹项目 obia-segmentation（零拷贝），测试断言两边是同一个函数对象——杜绝"两边指标各自演化"的暗坑。SAM 的 mask 按 predicted_iou 降序"先到先得"涂写成 label 图；没被任何 mask 盖住的像素记为未覆盖区（如实在账）。

两口径为什么必须分开：同类相邻田块的边界在"地类真值"里不存在，cls_bF1 天然偏宽容；衡量分割本身要用 seg_bF1 对图斑真值。混用口径是对比实验里最隐蔽的造假方式。

4 · 动手玩：AMG mask 是怎么变成"分割图"的

AMG 返回几百个互相重叠的候选 mask。涂写规则：按 predicted_iou 降序，每个像素归第一个（最高分）盖住它的 mask（先到先得）；谁都没盖住 → 未覆盖。点 ▶ 看涂写过程（SAM2 默认 AMG，pps=32，真实数据前 6 大对象）：

点的失败模式：覆盖率 0.92 很高，但越界率 0.32——点告诉 SAM"从哪开始"，没说"到哪停"，mask 顺着同类光谱漫溢到邻斑。框把 spill 压到 0.089。地类差异：点提示下 builtup 只有 IoU 0.26（块状纹理碎切），框提到 0.68。

三种选择：要矢量图斑+可解释特征+高 OA 自动分类 → OBIA；要贴边界的快速勾绘/样本预标注 → SAM2（+框提示）；要"对象≈图斑"的尺度语义 → 只有 OBIA 的 scale 参数给得了。
