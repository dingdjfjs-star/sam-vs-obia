# sam-vs-obia 质检报告（2026-11-20）

> 全部问题为本次实跑过程中真实发生、现场修复；测试门 `test/test.py` 8 项断言全绿（A1 桥接 / A2 场景 bit-exact / A3 summary 存在 / A4 四方指标 1e-9 复算一致 / A5 JSON 往返 / A6 提示记录健全）。

## 一、环境与工程（6 处）

1. **工作区 Bash 工具非真 bash**：`{...}` 分组、`VAR=x;` 赋值、多行 `python -c` 被肢解成碎片误执行——首次"环境装好"是假象（`STEP2_OK` 为碎片回显，`E:/Ana/envs/samgeo` 实际不存在）。修复：放弃复合命令，每条调用只跑一条简单命令；先 `python --version` 验证再继续。**教训：任何"成功"回显必须用独立命令实证。**
2. **`cmd //c` 执行含中文路径的 .bat 静默失败**：只弹交互提示符、不执行、exit 0。修复：绕开 bat，直接用 Bash 逐条串联；setup_env.bat 保留为文档并标注废弃。
3. **segment-geospatial 1.4.2 的 `sam2` 依赖藏在 extra**：`pip install segment-geospatial` 不带 `sam2`，`SamGeo2` 一用就 `ModuleNotFoundError`（其 samgeo2.py L111 `from sam2.automatic_mask_generator import ...`）。修复：`pip install "segment-geospatial[samgeo2]"`。
4. **HF 权重通道双重故障**：huggingface.co 直连被阻（预期内）；改走 hf-mirror 后 API 元数据通、但文件下载挂在 0 字节（`.incomplete`）——SAM2 系仓库已迁移 Xet 存储，hf-mirror 的 Xet 文件代理 502。修复：改 ModelScope 镜像 `AI-ModelScope/sam2-hiera-small`，curl 断点续传下载；**sha256=95949964d4e548409021d47b22712d5f1abf2564cc0c3c765ba599a24ac7dce3 与 HF LFS blob 指纹逐字节一致**（等价性实证，见 README §6）。
5. **`multiresolution_segment` 返回 `(labels, info)` 二元组**：只看签名没看 Returns，`np.asarray(labels)` 炸 `inhomogeneous shape`。修复：解包二元组并把 info（n_merges/官方秒数）记入 runs.jsonl。
6. **AMG mask 涂写顺序不确定风险**：sam2 AMG 返回顺序不保证按分数。修复：masks_to_labelmap 内显式按 `predicted_iou` 降序排序后"先到先得"涂写。

## 二、实验协议设计（2 处，防患于未然）

7. **口径漂移风险**：对比实验若复制 obia 的指标代码，两边实现会各自演化。设计决策：`obiabridge` 只挂 sys.path 零拷贝复用，测试 A1 断言指标实现为同一对象。
8. **AMG 未覆盖区**：SAM2 默认阈值下 23.2% 像素被过滤成 0——直接喂下游特征管线会炸（labels 需连续 1..K）。修复：`fill_uncovered` 最近邻距离变换并入相邻段，`uncovered_frac` 逐 run 记录在案，README 诚实声明。

## 三、出图与汇总（4 处）

9. fig2 布局越界（4 图塞 3 格 → IndexError 3 out of bounds）：改 2×3 重排（真值/OBIA/SLIC + SAM/两误差图）。
10. `error_overlay` RGBA 通道数错（ov 用 3 通道赋 4 分量 → shape mismatch）：改 `shape[:2]+(4,)`。
11. `summary["prompts"]["summary"]` 多套了一层 key（build_summary 里 psum 已是内层 dict）：修 make_figures 取用层级。
12. OBIA 记录缺 `scale` 键（fig3 x 轴取值 KeyError）：build_summary 组装 obia_scale_sweep 时补 `rec["scale"]=s`。

## 四、跨项目对账（公平性验证，非 bug）

- scale5 925 对象 / scale10 440 对象、seg_bF1 0.2489/0.2508 → 与 obia-segmentation README 敏感性表逐档吻合；
- SLIC 行 OA 0.9452 / 椒盐率 0.0002 / cls_bF1 0.2851 → 与 obia README §6.3 表（0.945/0.0002/0.285）吻合；
- 场景 70 图斑 / 5 类、测试 A2 bit-exact → 两个项目看到同一幅影像。

**终态结论**：对比实验数据链完整可溯源（runs.jsonl → summary.json → README/教程），测试 8/8 全绿，达到定稿标准。
